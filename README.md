Python – 100+ Desafios Resolvidos

Repositório com mais de 100 desafios resolvidos do curso de Python do professor Gustavo Guanabara.
Os exercícios estão organizados conforme a estrutura original do curso:

Mundo 1 – Fundamentos da linguagem
Mundo 2 – Estruturas de controle
Mundo 3 – Estruturas compostas

Além disso, o repositório também inclui:
Exercícios de fixação
Práticas adicionais para reforço de lógica de programação
Resoluções comentadas quando aplicável

Objetivo
Consolidar os fundamentos de Python e fortalecer a base em lógica de programação por meio de prática constante.
Este repositório representa minha evolução no aprendizado da linguagem e também serve como material de consulta futura.
